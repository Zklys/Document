# 图书管理员？
“虽然我也不清楚，但是确实是莫名奇妙地成为了这里的员工。”我对着面前的中年人说着。
“....”
不过显然，对方并没有把我说过的话听进去。
不过也是，他并没有义务听我发牢骚。
唉。
“姓名，年龄，以及准备要多长时间？”
我没再说什么，打算把他的信息登记在系统里。
“古德·瑞恩，1132岁，时间...按什么来算？”
我的天老爷，他终于舍得说话了，从他进店开始，除了要那本书，别的我无论说什么他都不说话。
“按店里的钟表记。”
我记得这一项我在早些时候在手册里看到过。
“那就30天。”
我把时间输上去。
“好了。”
古德奇怪的看了我一眼，什么都没说就准备起身离开。
我脸上沾了什么东西吗？。
我真是服了，大早上的，遇见的唯一一个人，看着还不太正常。
还记得早上一睁眼，我就出现在了这个奇怪的地方。
面前还有我的工牌。
我之前确实是找不到工作，在各种招聘软件上乱投简历，但是也不能这届把我抓过来干活吧。
而且我完全不知道我该干什么，除了在旁边一个比我头都厚的一本名为《员工手册》的东西，9千多页，鬼才看的完啊。
（不过确实，可能，大概，或许会有用。）
所以薪资呢？
我确实无聊地翻了一会儿，里面详细介绍了这里的方方面面。
所以薪资呢？
这是是个图书馆，有人能借书，也能看书，也能收书，里面还有很多关于这里的规矩，不过我身为店员是不用遵守的。
所以薪资呢？
我翻了三个小时，什么乱七八糟的都看见了，就是没看到薪资待遇。
不会没有吧，我该不会被拐来当白工了吧。
那还说啥了，跑路了兄弟们，跑路了。
跑不了了兄弟们。
我走出门就被传送回来了。
为什么我花了两秒就接受了出不去了事实。
因为回来是从一米多高掉下来的。
于是我捂着屁股回到了工位。
# 边境图书馆
也不知道昨天书怎么样。
二楼有个宿舍，我在二楼睡的。
其实感觉这也挺好，一楼的电脑不错，也能上网，平时打打游戏什么的都行。
快递和外卖还没试过，吃饭也是在二楼解决的，有厨房，不错。
虽然还不知道薪资是多少，但是我昨天好像忘记收钱了。
到时候收钱自己用，反正那手册上都写了能收。
等那个古德还书的时候问他要吧。
“图书馆？之前还没见过这里有。”一名贵妇牵着一条泰迪犬走了进来呢。
“宠物禁止入内。”
讲实话，我对这种宠物没什么好感，既不好看，也不温顺，真是不知道哪些人还在养这种东西。
“30枚银币，开个情面。”贵妇说着，往桌上放了个小袋子。
银币？什么年代了，还在用银币。这不会是在逗我玩的吧。
“真不行。”
“60枚。不要把事情弄的太死。”
有是一小包放在了桌子上。
唉，算了，懒得理她，待会儿我再打扫一遍吧。
我再翻开员工手册，打算看看违反有没有后果。
不过我倒是翻到了货币对照表。
1金币=100银币。
1银币=10000铜币。
这通货膨胀挺严重啊。
1铜币=0.01元。
1银币=100元。
1金币=10000元。
算了，当我没说。
这钱是真的能换啊。
1不妥=10元。
这啥？
算了，不管了。
我先去把那6000块揣兜里再说。
“哎哎！”
等我扭头看过去的时候狗已经死了。
那这狗很短命了。
不过不难想象，我接下来要和这个女人吵到什么时候。
“...”
奇怪，她怎么还没来找事？
“麻烦你处理一下了。”
看来不是我想的那种人。
我在柜台找了点袋子，然后把那死狗装了进去。
“我带走，钱也不用退，这狗东西不争气。”说完，贵妇把那死狗直接带走了。
不过这钱怎么换呢？
这钱看着挺不错的，看着像是工艺品一样。
算了，我直接丢到了柜台随便的一个抽屉里了。
