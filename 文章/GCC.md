# GCC
## GNU
- GNU是一个操作系统，其内容软件完全以GPL方式发布。这个操作系统是GNU计划的主要目标，名称来自GNU's Not Unix!的递归缩写。
- 因为GNU的设计类似Unix，但它不包含具著作权的Unix代码。GNU的创始人，理查德·马修·斯托曼，将GNU视为“达成社会目的技术方法”。
- 作为操作系统，GNU的发展仍未完成，其中最大的问题是具有完备功能的内核尚未被开发成功。GNU的内核，称为Hurd，是自由软件基金会发展的重点，但是其发展尚未成熟。
- 在实际使用上，多半使用Linux内核、FreeBSD等替代方案，作为系统核心，其中主要的操作系统是Linux的发行版。
- Linux操作系统包涵了Linux内核与其他自由软件项目中的GNU组件和软件，可以被称为GNU/Linux（见GNU/Linux命名争议）。
## MinGW
- [Mingw-w64](https://www.mingw-w64.org/) 是头文件、导入库、库和工具的集合 当与编译器工具链（例如 GCC 或 LLVM）结合使用时，会提供 用于构建本机 Windows 应用程序的完整开发环境和 图书馆。
- Mingw-w64 是原始 `mingw.org` 项目的改进，该项目创建 以支持 Windows 系统上的 GCC 编译器。它于 2007 年按顺序分叉 提供 64 位支持和更新的 API。从那时起，它得到了广泛的使用和 分配
## 程序生成的过程(编译与链接)
### 编译
- 编译时指使用编译工具对源文件进行翻译为二进制文件的操作
#### 编译过程
##### 预编译
```shell
gcc -E 源文件
```
- 生成预编译文件后缀为`.i`
##### 汇编
```shell
gcc -S 源文件/.i
```
- 生成汇编文件后缀为`.s`
##### 转为二进制
```shell
gcc -c 源文件/.s/.i
```
- 生成二进制文件后缀为`.o`
### 链接
```shell
gcc .o .o ... 
```
- 将二进制文件链接转为可执行文件
- 处理文件依赖问题
## GCC介绍
- GNU 编译器集合包括 `C、C++、 Objective-C，Fortran， Ada、Go、D、Modula-2` 和 `COBOL` 以及这些语言的库 （libstdc++,...）。 [GCC](https://gcc.gnu.org/) 最初是作为 GNU作系统的编译器编写的。 GNU 系统被开发为 100% 自由软件，从某种意义上说是自由的 它尊重 用户的自由。
## GCC的具体命令
1. `gcc --version`		查看gcc版本
2. `gcc 文件名`		编译单个文件，默认用a作为文件名后缀为可执行文件的后缀名
3. `gcc 文件名1 -o 文件名2`	编译 文件2 同时将编译生成的 文件名 改为 文件名1
4. `gcc -o 文件名1 文件名2`	编译 文件2 同时将编译生成的 文件名 改为 文件名1
5. `gcc -E` 文件名1		输出预处理文件后缀为`i`
6. `gcc -S` 预处理文件 		输出汇编文件后缀为`s`
7. `gcc -c `汇编文件		输出二进制文件后缀为`o`
8. `gcc -o` 文件名1 二进制文件	输出文件为文件名1的可执行文件
9. `gcc -static`		静态链接，默认使用动态链接
10. `gcc -fexec-charset=GBK` 	指定运行时编码为`GBK`
11. `gcc -finput-charset=UTF-8` 	指定源文件编码为`UTF-8`
12. `gcc -Wall`			开启所有警告
13. `gcc -Wunused-variable`	开启常见警告
14. `gcc -Wno-警告名`		关闭指定警告
15. `gcc -Werror`		将警告当做错误处理
16. `gcc -O<0~3>`		由不优化到三级优化
17. `gcc 文件名1 文件名2`		同时编译文件1和文件2
18. `gcc *.c`			同时编译所有的`.c`文件
19. `gcc -L库文件路径 -l库名`	使用静态链接库
20. `ar rcs + 静态库文件的名字 + 目标文件列表` 生成静态链接库
21. `gcc  .dll -FPIC -shared .c .c` 	生成动态链接库
22. `gcc -Wl -rath 目录`		指定搜索路径的动态库(仅限`Linux`)
23. `gcc .dll -shared .o .o`	生成动态链接库(生成`.o`文件是要加上` -FPIC`)
